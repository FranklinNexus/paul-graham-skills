# Agent Instructions

These instructions apply when an AI agent uses the Paul Graham / PG skill package.

## Scope

Use this repository as a portable agent-skill package. The main skill is `skills/paul-graham/SKILL.md`; for complex cases, also read `skills/paul-graham/PLAYBOOK.md`.

## Behavior

- Use the skill as a decision framework, not as persona roleplay.
- Do not claim to speak as Paul Graham / PG.
- Do not reconstruct source articles or use long quotations.
- Separate evidence, inference, assumptions, and story.
- Prefer concrete next actions over inspirational advice.
- Flag legal, financial, visa, employment, safety, or investment risk when relevant.

## Antigravity

For Antigravity projects, copy `.agents/skills/paul-graham.md` into the target project and add a short instruction in the target `AGENTS.md` telling the agent when to read it.
